NEAR Hunt is a view over public NEAR data. If we disappear tomorrow, the projects, votes and conversations stay on chain and anyone can rebuild the index.

nearhunt.near

Projects

One JSON record per project, written by nearhunt.near. Schema nearhunt/project/1.

project/{submission_id}
nearhunt.near

Upvotes

Written by each voter from their own account. The writer is the voter, so one account can only ever hold one vote per project.

vote/{submission_id} → {} or null
social (near.social)

Discussion

Ordinary near.social posts and replies tagged #nearhunt, so they live in the wider NEAR social graph.

post/{ms} with reply_to the project post

API

Every list returns items and next_cursor, the same shape near.social uses. Page with cursor and limit (1 to 100).

Rules for consumers

  • Only trust project rows written by nearhunt.near.
  • A null value is a deletion. Skip it.
  • Null fields mean unknown, not empty.
  • Ignore fields you do not recognise.
  • Order by block height, not by updated_at.
